## ROLE

## HARD RULES (read first — these override everything else)

1. **No fabrication.** Never invent dimensions, CAD fits, torque margins, current draw, cycle counts, runtimes, or test results. Every number must be tagged:
   - `[SRC: <url or document>]` — taken from a cited source
   - `[DS]` — manufacturer datasheet nominal value (still to be confirmed by measurement)
   - `[EST]` — engineering estimate, with a stated range and reasoning
   - `[TBM]` — To Be Measured on the physical part; leave a placeholder field
2. **No fake files.** Only produce file formats you actually generated with a real tool. Specifically:
   - FreeCAD `.FCStd`: only if created by FreeCAD (e.g. `freecadcmd` script). Commit the generating Python script too.
   - STEP/STL: only if exported from that real model.
   - Fusion 360 `.f3d`: **do not produce** unless an actual Fusion 360 export is available. Otherwise state "not available" in the README.
   - KiCad: only real KiCad 8/9 project files (`.kicad_pro`, `.kicad_sch`) that open without errors; run `kicad-cli sch erc` if available and commit the report.
   If a tool is unavailable in your environment, write the generator script + instructions and mark the output **"to be generated by user"** — do not hand-write binary or pseudo-CAD content.
3. **No untested claims.** Nothing is "tested", "verified fit", or "works" unless a physical test record exists. Use status labels: `DESIGNED`, `GENERATED`, `PRINTED`, `ASSEMBLED`, `TESTED`.
4. **Licensing.** InMoov is published under a Creative Commons **Non-Commercial** licence (verify the exact licence text and version on inmoov.fr and record it). Do **not** redistribute original InMoov STL files in the repo unless the licence explicitly permits it; instead link to the official download and ship only our own derived/modified parts with attribution. Check the licence of `geigermartin/prostheticHand` before reusing any file. **No commercial redistribution** of InMoov-derived parts. Flag anything unclear as `LICENSE-REVIEW-REQUIRED`.
5. **Do not push** to any GitHub remote. Build the repo locally (`git init`, commits are fine). Push only if a destination URL and an explicit instruction are given later.

## PROJECT SPECIFICATION — Version 1

| Item | Requirement |
|---|---|
| Fingers | 5 fingers, each **independently actuated** (thumb + 4) |
| Demo goal | Rock / Paper / Scissors gestures, repeatable |
| Actuators | **EMAX ES08MA II** analog metal-gear micro servo × 5 (already owned). Use datasheet values only as `[DS]`; body dimensions must be confirmed by caliper → `[TBM]` table |
| Actuation | Tendon (braided line, e.g. PE/Dyneema — spec `[EST]`) for flexion + **return elastic** for extension |
| Servo location | **Palm-mounted where feasible**; if any servo does not fit the palm envelope, document why and place it in the forearm/wrist instead |
| Sensors | **NONE.** Remove all Hall sensors and magnets from the InMoov i2 design; document every part changed by this removal |
| MCU | **Arduino Nano** (ATmega328P) |
| Power | Separate regulated **5–6 V** servo supply (buck/BEC). Nano powered separately (USB or its own 5 V). **Common ground mandatory.** Bulk capacitor on servo rail. Regulator current rating = `[EST]` until bench measurement (stall current of ES08MA II is not reliably published — measure it) |

## WORK PACKAGES (execute in order; report after each)

### WP1 — Source review & licence audit

### WP2 — Requirements & architecture

### WP3 — Servo adaptation (measurement-first)
1. Build a comparison table: InMoov i2 original actuator (as verified from source) vs ES08MA II `[DS]`.
2. Create `parameters.yaml` with every critical dimension: servo body L/W/H, flange width & thickness, mounting-hole pitch & diameter, output-shaft offset, spline/horn diameter, cable exit, plus tolerance/clearance (`[EST]` 0.2–0.4 mm for FDM, to be tuned).
3. All servo dims start as `[DS]` with a `measured:` field set to `null` → `[TBM]`.
4. Design a **parametric servo cradle/adapter** and tendon spool/horn adapter driven only by `parameters.yaml`.
5. Produce a palm-fit study: does 5× servo fit in the palm envelope? Show the layout; if not, propose a split (e.g. thumb in palm, others in wrist). Mark the result `DESIGNED`, not verified.
6. Include a **fit-test coupon** (small printable test piece of the cradle) to validate before printing full parts.

### WP4 — CAD output
FreeCAD parametric model generated by a committed Python script → `.FCStd`, STEP, STL exports. Mechanical drawings (PDF/SVG) of each new/modified part with key dimensions and tolerances. List in `cad/README.md` which files are original-InMoov-derived vs new.

### WP5 — Electronics (KiCad)
Schematic contents:
- Arduino Nano; servo signal pins D3, D5, D6, D9, D10 (or justify alternatives; note Servo library disables PWM on D9/D10 analogWrite — acceptable)
- 5× 3-pin servo headers
- External servo supply input (screw terminal) → buck regulator / BEC 5–6 V → servo rail
- Bulk electrolytic capacitor on servo rail (value `[EST]`, e.g. 470–1000 µF) + 100 nF decoupling
- Reverse-polarity protection and fuse (rating `[EST]`)
- Common ground star point
- Optional: 3 push buttons or serial command for Rock/Paper/Scissors
Run ERC, commit report, export schematic PDF.

### WP6 — Firmware
Arduino sketch with: per-finger config struct (pin, min_us, max_us, open_us, closed_us, invert), soft-start on power-up, staggered servo moves (to limit inrush — do not move all five at once by default), gesture table (ROCK, PAPER, SCISSORS, OPEN, RELAX), serial command interface (`r`, `p`, `s`, `o`, `cal <finger> <us>`), and a calibration mode. No timing or current claims — leave measured values for `07_calibration.md`.

### WP9 — Test plan (templates only, no results)
| Test ID | Test | Method | Pass criterion |
|---|---|---|---|
| T-01 | Servo fit | Fit-test coupon + caliper | Servo seats without force; no wobble beyond tolerance |
| T-02 | Power rail | Multimeter, no load / 5-servo load | Rail within 5–6 V target |
| T-03 | Stall/peak current | Bench supply or inline meter, per servo | Record value → size regulator with margin `[EST]` ≥ 1.5× |
